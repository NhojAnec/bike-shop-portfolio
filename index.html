SRK's Bike Shop

A text-based ordering program for a bike shop. The customer builds a bike by choosing a frame, a colour and an accessory. The program then adds up the price and prints a receipt to a text file.

Python 3 Runs in the terminal true_project.py info.txt
How it works

From menu to receipt

  1. Main menuContact Us, About Us, or Order Now
  2. FramePick 1 of 4, then confirm with Y/N
  3. ColourPick 1 of 7, then confirm
  4. AccessoryPick 1 of 5, then confirm
  5. ReceiptTotal shown on screen and saved to info.txt

The program has two files. true_project.py is the program itself. info.txt is the receipt it writes after each order.

def print_list(input_list):

def print_order(input,num):
    print(input[num-1]['ID'], input[num-1]['item'], input[num-1]['price'], input[num-1]['currency'])
def write_texts(input,num):
    write_file.writelines("\t".join((input[num-1]['ID'], input[num-1]['item'], input[num-1]['price'])))
def order_confirm(list):
    price_type = 0
    while True:
        print_list(list)
        print("=" * 20)
        user = input("Please select your option: ")
        if user == "1":
            print("-" * 20)
            print_order(list,1)
            print("-" * 20)
            confirm = input("Confirm your selection? (Y/N):")
            if confirm == 'Y':
                price_type += (float(list[0]['price']))
                write_texts(list,1)
                price.append(price_type)
                print("=" * 20)
                break
            elif confirm == 'N':
                print("=" * 20)
            else:
                print("Please enter correct promt.(Case sensitive)")
                print("=" * 20)
        # Options "2" to "4" repeat the same steps for list[1] to list[3].
        elif user == "5":
            try:
                print("=" * 20)
                print_order(list,5)
                print("=" * 20)
            except Exception:
                print("Out of Range")
                print("-" * 20)
            else:
                confirm = input("Confirm your selection? (Y/N):")
                if confirm == 'Y':
                    price_type += (float(list[4]['price']))
                    write_texts(list,5)
                    price.append(price_type)
                    print("=" * 20)
                    break
                elif confirm == 'N':
                    print("=" * 20)
                else:
                    print("Please enter correct promt.(Case sensitive)")
                    print("=" * 20)
        # Options "6" and "7" repeat the same steps for list[5] and list[6].
        else:
            print("=" * 20)
            print("Please enter correct action number.")
            print("=" * 20)

    • 
      
  • Accept a lowercase y or n as well, so the confirm step is not case sensitive.
    • 
      
  • Save each receipt under its own name, such as a timestamp, so a new order doesn't overwrite the old one.
    • 
      
  • Use with open(...) so the file always closes, even if the program stops early.
